# Habit Tracker App - Deployed on Vercel

Una aplicación web moderna para trackear y monitorear tus hábitos diarios. Desarrollada con React y Vite.

## 🔗 Acceso en Línea

**URL de Producción:** https://habit-tracker-app.vercel.app

¡Accede desde cualquier dispositivo!

## 🎯 Características

- ✅ Crear y gestionar hábitos
- 📊 Visualizar progreso diario
- 📈 Estadísticas y análisis
- 🎨 Interfaz intuitiva y responsiva
- 💾 Almacenamiento local (localStorage)
- 🌐 Disponible en línea desde cualquier dispositivo

## 📱 Acceso Móvil

1. Abre tu navegador en el celular
2. Ve a: **https://habit-tracker-app.vercel.app**
3. ¡A trackear hábitos!

## 🏠 Instalar Localmente (Opcional)

```bash
git clone https://github.com/estarlin275/habit-tracker-app.git
cd habit-tracker-app
npm install
npm run dev
```

## 📁 Estructura del Proyecto

```
habit-tracker-app/
├── src/
│   ├── components/        # Componentes React
│   ├── pages/            # Páginas principales
│   ├── styles/           # Estilos CSS
│   ├── App.jsx           # Componente principal
│   └── main.jsx          # Punto de entrada
├── public/               # Archivos estáticos
├── index.html            # HTML template
├── package.json          # Dependencias
├── vite.config.js        # Configuración de Vite
├── vercel.json           # Configuración de Vercel
└── README.md             # Este archivo
```

## 🛠️ Tecnologías

- **Frontend**: React 18, Vite
- **Estilos**: CSS Modules
- **Almacenamiento**: localStorage
- **Deploy**: Vercel
- **Fechas**: date-fns

## 🚀 Despliegue Automático

Cada push a la rama `main` automáticamente deploya la app en Vercel.
